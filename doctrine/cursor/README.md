# Cursor IDE Integration (Canonical Source)

This directory contains the canonical Cursor configuration that travels with the
doctrine subtree. The root `.cursor/` directory in consuming repositories is
populated from here via `tools/scripts/setup-cursor.sh`.

## Contents

| Component | Path | Distribution |
|-----------|------|-------------|
| Hook config | `hooks.json` | Symlinked or copied to `.cursor/hooks.json` |
| Hook scripts | `hooks/` (5 scripts) | Symlinked or copied to `.cursor/hooks/` |
| Rules template | — | Rules are project-specific (see source repo's `.cursor/rules/` as reference) |
| Skills | — | Generated by `tools/scripts/deploy-cursor-skills.js` from `doctrine/approaches/` and `doctrine/shorthands/` |

## Setup

```bash
# From a consuming repository that has doctrine/ via subtree:
./doctrine/cursor/setup.sh

# Or with explicit paths:
tools/scripts/setup-cursor.sh --source doctrine/cursor --target .cursor
```

## Architecture

```
doctrine/cursor/         ← Canonical source (travels with subtree)
├── hooks.json           ← Hook configuration
├── hooks/               ← Validation and advisory hook scripts
│   ├── validate-doctrine-edit.sh
│   ├── check-work-log.sh
│   ├── check-markdown-lint.sh
│   ├── warn-sensitive-edit.sh
│   └── session-init.sh
├── setup.sh             ← Convenience wrapper for consuming repos
└── README.md

.cursor/                 ← Cursor reads from here (repo root)
├── hooks.json           → symlink to doctrine/cursor/hooks.json
├── hooks/               → symlink to doctrine/cursor/hooks/
├── skills/              ← Generated (not from subtree)
└── rules/               ← Project-specific (not from subtree)
```
